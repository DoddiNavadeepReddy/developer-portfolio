# Doddi Navadeep Reddy — Developer Portfolio

Personal developer portfolio for **Doddi Navadeep Reddy**, Computer Science & Engineering student at REVA University.
Inspired by the minimalist, editorial aesthetic and UX architecture of [Cian Goon's Developer Portfolio](https://www.ciangoon.dev/).

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS + Pure CSS tokens
- **Typography**: Inter, Plus Jakarta Sans, JetBrains Mono
- **Icons**: Lucide Icons
- **Linting**: Oxlint

## 📂 Featured Projects

1. **CrimeShield — Smart Emergency Response System**
   - *Type*: IoT / Emergency Response Prototype
   - *Tech*: ESP32-CAM, NEO-6M GPS, React, Vite, Node.js, Express, Socket.IO, Supabase, Twilio
2. **E-Commerce Product Recommendation System**
   - *Type*: Academic / System Design Project
   - *Modules*: User Profiling, Recommendation Engine, Catalog, Feedback Analysis, Search, Analytics
3. **LeetCode / DSA Solutions**
   - *Type*: Programming / Problem Solving
   - *Repository*: [DoddiNavadeepReddy/leetcode-solutions](https://github.com/DoddiNavadeepReddy/leetcode-solutions)

## 🚀 Local Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build production bundle
npm run build

# Run linter
npm run lint
```

## 🌐 Live Deployment

Automatically deployed to GitHub Pages via GitHub Actions upon push to `main`.
